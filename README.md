# 2026电赛-H题-车载平衡滚球运动控制系统
 小车循迹和滚球平衡是两个相对独立的系统,两个系统之间无串口通信。控制滚球平衡的舵机直接由视觉模块（K230）控制。循迹部分和滚球控制部分仅有电源部分共用。<br>
## 快速复刻
按照信号线物理接线.md连接杜邦线<br>
注意：（调试经验）控制舵机的5v供电引脚不能直接从K230上连接（否则会烧），需要从5V5A降压模块接出。舵机的GND端需要与K230的GND接到一起。
### 小车循迹模块:<br>
 1、下载LineFollow.zip后解压。<br>
 2、使用keil打开路径LineFollow/projiect/Keil/SeekFree_MSPM0G3507_Device_Library.uvprojx<br>
 3、使用DAP下载器连接MSPM0G3507核心板，编译烧录。<br>  
### 滚球控制模块:<br>
1、下载main.py<br>
2、使用tpye-c接口连接K230和电脑，将main.py拷入k230的sd卡中（sdcard而不是data）<br>
（注：K230的sd卡初始化步骤见淘宝幻尔机器人提供的资料包） <br>
链接: https://pan.baidu.com/s/1h4ChUXApCscN0UfuirByRQ 提取码: un33<br>
## 使用指南
### 小车循迹模块:<br>
将电池的XT60接口与MSPM0G3507学习拓展板插合，先将学习拓展板上的电源主开关置于ON，并通过IO按键接口选择模式(默认模式为日常巡线模式)，然后再将DRV870E电机驱动模块开关置于ON<br>
在逐飞科技MSPM0G3507学习拓展板上，有4个IO按键接口分别对应：<br>
| 引脚   | 模式名称 | 基础速度 base_pwm | 用途 |
|:------:|:--------:|:----------------:|:----------:|
| A30| 2小问    | 4000              | 调试 / 窄弯 |
| A31| 4小问    | 2800              | 日常巡线 |
| B0 | 快速     | 6000              | 高速赛道 |
| B1 | 冲刺     | 7000              | 极速 |

### 滚球控制模块:<br>
正常上电即可使用
## 快速调参
### 小车循迹模块:<br>
小车循迹模块调参主要是四种循迹模式的PID参数：<br>
使用打开project/keil/SeekFree_MSPM0G3507_Device_Library.uvprojx，在code下打开Five _Track.c  23至62行代码为四种循迹模式的PID参数调参<br>
### 滚球控制模块:<br>
在完成硬件安装与K230开发板的固定后，部分参数可能不能直接使用，需要微调，具体见下：<br>
##### 识别区域（蓝色矩形框）参数：
在main.py的图像检测与RIO配置部分 （约第26行）。具体的，在IDE上框出待识别的水管区域，并在IDE上读出x，y ，w，h四个值并按照(y/2, x/2, h/2, w/2)的顺序填入第26行。<br>
##### 小球识别参数：
在main.py第35到第39行，参数含义代码注释。<br>
##### PID控制参数：
在main.py第54，58，62行，参数含义代码注释。<br>
##### PWM限度参数：
在main.py第74，75，78行。使用舵机调试器连接舵机，将舵机机械结构允许的最大脉冲宽度和最小脉冲宽度分别填入75行，74行。当水管水平于地面，滚球可以在水管中可以保持静止的，将此时的脉冲宽度写入第78行。<br>
